Problem Statement

The Urban Spatial Failure Mode

Unorganized Baseline (Random Search)

  • Cruising Congestion: Drivers circle rows randomly, increasing search distance by +129%.
  • Charger Misuse: ICEs and high-battery EVs block scarce 50kW fast chargers (26 incidents / 150 batch).
  • Severe Emissions: Stop-and-go cruising multiplies localized carbon footprint.

Organized Software Solution

  • Global State Coordination: Instant spatial assignment at Entrance Gate (0,0).
  • Strict EV Priority Protocol: Low-battery EVs (≤25%) guaranteed charger access.
  • Zero Misuse Policy: ICE vehicles strictly routed to standard bays (100% elimination).

Algorithmic Design

Core Allocation Logic (Strict Protocol)

// Threshold Constraint
LOW_BATTERY_THRESHOLD = 25%
IF vehicle is EV AND battery ≤ 25%:
→ Assign nearest FREE EV Charging Spot
→ Fallback to nearest FREE Regular Spot ONLY IF all EV spots are occupied
ELSE IF vehicle is EV AND battery > 25%:
→ Assign nearest FREE Regular Spot (reserving chargers for critical demand)
ELSE (non-EV vehicle):
→ Assign nearest FREE Regular Spot ONLY (Strict zero-misuse policy)
